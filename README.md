# ออกแบบเสายาว (Slender Column) ตาม ACI 318-19 — Streamlit

เว็บแอปสำหรับออกแบบ/ตรวจสอบเสาคอนกรีตเสริมเหล็กที่มีความชะลูด ด้วยวิธีขยายโมเมนต์ (Moment Magnification Method) ตาม ACI 318-19

## วิธีใช้งาน

```bash
pip install -r requirements.txt
streamlit run app.py
```

แล้วเปิดเบราว์เซอร์ที่ http://localhost:8501 — กรอกข้อมูลทางแถบด้านซ้าย ผลลัพธ์จะอัปเดตทันที

## ความสามารถ

| หัวข้อ | รายละเอียด | ACI 318-19 |
|---|---|---|
| หน้าตัด | สี่เหลี่ยม / วงกลม, ปลอกเดี่ยว / ปลอกเกลียว | — |
| ความชะลูด | kℓu/r เทียบขีดจำกัด (ไม่เซ: 34+12M1/M2 ≤ 40, เซ: 22), r = 0.3h / 0.25D | 6.2.5 |
| ค่า k | กำหนดเอง หรือคำนวณจาก ψA, ψB (สมการ Alignment chart) | R6.2.5 |
| (EI)eff | สูตร (a), (b), (c) | 6.6.4.4.4 |
| โครงไม่เซ | Cm, Pc, δns, M2,min | 6.6.4.5 |
| โครงเซ | δs จาก Q หรือ ΣPu/ΣPc, M = Mns + δsMs และตรวจ P-δ ตามความยาว | 6.6.4.6 |
| Interaction diagram | Strain compatibility, φ ตาม εt (εty + 0.003), φPn,max | 21.2.2, 22.2, 22.4 |
| รายละเอียดเหล็ก | ρg 1–8%, จำนวนเหล็กขั้นต่ำ, ระยะช่องว่าง, ขนาด/ระยะเรียงปลอก | 10.6.1.1, 10.7.3.1, 25.2.3, 25.7.2 |

หน้าจอผลลัพธ์แบ่งเป็น 4 แท็บ: **สรุปผล**, **Interaction Diagram** (โต้ตอบได้ + ดาวน์โหลด CSV), **รายการคำนวณ** (แสดงสมการทีละขั้น), **หน้าตัดเสา**

## โครงสร้างไฟล์

- `app.py` — หน้า UI ของ Streamlit
- `aci318_column.py` — ฟังก์ชันคำนวณ (ใช้แยกได้โดยไม่ต้องมี Streamlit)
- `.streamlit/config.toml` — ธีมสีของแอป

## ข้อจำกัด

- ดัดแกนเดียว (หากต้องการตรวจอีกแกน ให้สลับค่า b และ h)
- คอนกรีตน้ำหนักปกติ, Ec = 4700√f'c (แก้ไขได้)
- kℓu/r > 100 ต้องใช้การวิเคราะห์อันดับสองแบบไม่เชิงเส้น (6.2.6) — โปรแกรมจะแจ้งเตือน
- เป็นเครื่องมือช่วยออกแบบ ผลลัพธ์ต้องตรวจสอบโดยวิศวกรผู้มีใบอนุญาต
